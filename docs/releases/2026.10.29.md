# Mission Gontrol 2026.10.29

Mission Gontrol adds repository-wide PR browsing and draggable terminal scrollback.

## PR browsing

- Open pull requests in the session's embedded browser and keep the selected PR associated with that session.
- Choose from the repository's open pull requests, including drafts, instead of relying only on the current branch.
- Match branch suggestions against the source repository as well as the branch name, including forked repositories.
- Access the PR picker in narrow panes and focused session windows.

## Terminal navigation and session defaults

- Drag the terminal scrollbar through available scrollback in agent sessions and regular terminals. The scrollbar appears only when the terminal has history.
- Codex starts and resumes with native terminal scrollback enabled. Its launch policy accepts the required flag while retaining permission checks.
- Configure per-agent session defaults, including permission bypass and Claude Chrome integration. Project preferences override global defaults.
- Claude's fullscreen renderer manages its own history. For the native scrollbar, run `/tui default` inside Claude; the conversation relaunches in the classic renderer. If the corner pet covers the thumb, move it aside before dragging.
- Retire the third-party Ship skill installer while retaining Mission Gontrol's bundled workflow skills.

## Other features

- Mission Gontrol branding, app icon, and installer identity; original Mission Control attribution remains in Settings and the MIT license.
- Keyboard command palette with `Cmd+K` or two quick Shift presses for projects, sessions, Settings, and common Git commands.
- Direct deletion of active, pinned, and archived sessions, with confirmation. Deleting a session leaves its Git worktree in place.
- Git history browsing, repository controls, configurable themes, and local voice transcription.
- Recall stays disabled. Previously saved Recall data remains intact.

## Downloads and upgrade

- **Apple Silicon:** `MissionGontrol-2026.10.29-arm64.dmg` for M1 and newer Macs.
- **Intel:** `MissionGontrol-2026.10.29-x64.dmg`.

Fully quit Mission Gontrol with `Cmd+Q`, open the matching DMG, and drag Mission Gontrol.app to Applications. Reopen the app after replacing it. Existing projects, sessions, and preferences retain their storage location; the app applies the additive Claude Chrome preference migration on startup.

These builds use ad-hoc signatures and are not Apple-notarized. If macOS blocks first launch, use System Settings → Privacy & Security → Open Anyway. Updates remain manual through GitHub Releases.
