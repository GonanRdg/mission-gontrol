# Mission Gontrol 2026.9.21

Mission Gontrol is the independently maintained fork of Mission Control by GonanRdg. Original attribution to AgentSystem Labs remains in Settings → General → Credits and the MIT license.

## New in this release

- New Mission Gontrol identity across the desktop app, Settings, prompts, installer names, and macOS permissions, with a green MG icon and independent bundle identifier.
- Recall is disabled across Settings, project menus, voice capture, automatic capture, code graphs, and agent integration. Existing saved memories are retained.
- Existing projects and preferences continue using their current storage location.
- Intel installers include an x64-compatible local speech server.
- Releases are built and published independently; upstream automatic tagging and Academy publication are disabled.

This release is based on v2026.9.8. The unfinished Actions workflow on `feat/actions` is reserved for a later release.

## Included fork features

- Direct Git fetch, pull, push, Commit & Push, and pull-request actions, plus a commit history browser with file diffs and configurable Git shortcuts.
- Painted Light appearance, theme-aware terminals and editors, and configurable accents.
- macOS Command shortcuts that preserve Control-key behavior inside Codex and Claude terminals, plus non-US keyboard improvements.
- Per-project diagram skills, improved session and transcript handling, local-only pets, and independent release credits.

## Downloads and upgrade

- Apple Silicon: `MissionGontrol-2026.9.21-arm64.dmg`
- Intel: `MissionGontrol-2026.9.21-x64.dmg`

Quit the previous app before launching Mission Gontrol. Both use the existing workspace data. Drag **Mission Gontrol.app** to Applications; the former MissionControl.app has a different name, so remove that old application separately if you no longer need it.

These builds use ad-hoc signatures and are not Apple-notarized. Updates remain manual through this repository's GitHub Releases.
